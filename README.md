# 🧠 Quiz App

<img width="1366" height="633" alt="Quiz Application" src="https://github.com/user-attachments/assets/c1b760e0-98fd-4500-949c-1190021b251c" />


A simple, interactive, and responsive **Quiz Application** built using **HTML, CSS, Bootstrap, and JavaScript**.

This application allows users to answer multiple-choice questions within a time limit, view their final score, and review their answers.

## ✨ Features

- 📝 Multiple-choice quiz questions with 4 options.
- ⏳ 30-second timer for each question.
- ⏭️ Automatically moves to the next question when time runs out.
- 🔘 Next button to move between questions.
- 📊 Displays the final quiz score.
- ✅ Shows correct and incorrect answers.
- 📋 Review Summary with questions, user answers, and correct answers.
- 🚫 Displays "Not Answered" for skipped questions.
- 🎨 Attractive gradient backgrounds and buttons.
- 📱 Responsive design using Bootstrap.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, gradients, and hover effects.
- **Bootstrap 5** – Responsive layout, cards, and buttons.
- **JavaScript** – Quiz functionality, timer, score calculation, and result display.

## ⚙️ How It Works

1. The quiz displays a question with four options.
2. The user selects an answer.
3. Each question has a 30-second timer.
4. The user can click the Next button to continue.
5. If the timer reaches zero, the next question appears automatically.
6. After the last question, the final score is displayed.
7. The Review Summary shows the user's answers and the correct answers.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Start answering the quiz questions!
